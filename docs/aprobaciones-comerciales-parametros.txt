API de aprobaciones comerciales: contrato consolidado

GET /api/reportes/aprobaciones-comerciales?periodo=202611

Parametros HTTP (en minusculas, sin prefijo p_):
- periodo: obligatorio, AAAAMM; 100001 a 999911, mes 01 a 12.
- cotizacion: opcional, numero comercial, hasta 100 caracteres.
- factura: opcional, numero de factura del pedido, hasta 100 caracteres.
- cliente: opcional, RUC exacto, hasta 100 caracteres; conservar ceros iniciales.
- sucursal: opcional, ID positivo BIGINT UNSIGNED de sucursal del cliente.
- aprobador_final: opcional, ID positivo BIGINT UNSIGNED de gp_usuarios.

Texto vacio o solo espacios se normaliza a NULL; los ID tambien admiten
vacio o ausencia como NULL. Cero no desactiva filtros.
Los identificadores se transportan como cadenas para conservar su precision.
tipo_documento y documento_id fueron retirados: valores presentes no vacios
devuelven HTTP 422. periodo ausente, vacio o invalido devuelve HTTP 422.

Ejemplos:
GET /api/reportes/aprobaciones-comerciales?periodo=202611
GET /api/reportes/aprobaciones-comerciales?periodo=202611&cotizacion=COT-001
GET /api/reportes/aprobaciones-comerciales?periodo=202611&cliente=0012345678001&sucursal=2&aprobador_final=15

El repositorio ejecuta en la conexion mysql, mediante parametros enlazados:
CALL tuvalapi.sp_consultar_aprobaciones_pedido(?, ?, ?, ?, ?, ?)
Orden: cotizacion, factura, cliente, sucursal, aprobador_final, periodo.

El periodo corresponde a fecha_hora_aprobacion_comercial de la decision
principal elegida por el SP, no a la creacion del pedido. La recuperacion del
aprobador de hi_cotizacion, las columnas factura/punto de venta y los motivos
son responsabilidad del SP; la API conserva los campos devueltos.
Punto de venta no es un filtro nuevo. sucursal corresponde al cliente.

Despliegue: requiere el SP de seis parametros instalado en cada entorno.
Este cambio no instala ni modifica procedimientos ni corrige su rendimiento.
Actualizar los consumidores del contrato anterior al desplegar la API.
Se conservan la ruta GET, middleware y formato de respuesta existentes.
